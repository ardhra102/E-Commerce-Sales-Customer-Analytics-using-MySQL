# E-Commerce-Sales-Customer-Analytics-using-MySQL
SQL analysis of an e-commerce platform's sales, customers, orders, and products using MySQL.

# 🛠️ Tools Used
MySQL Workbench

# 📊 Dataset
Source: Kaggle
,Dataset: E-Commerce Dataset
[https://www.kaggle.com/datasets/maramsa/e-commerce-sales-and-customer-analytics-dataset?]

# 🔍 Key Business Questions Answered
- Which customers have total spending higher than the average spending across all customers?
- Which is the highest-revenue product within each category?
- Which are the top three products in each category based on total sales value?
- What percentage of total sales value is generated by the top 10 customers?
- How can customers be ranked based on their total spending?

Through this project, I practiced using SQL to solve business-oriented problems involving customers, orders, products, and sales. I strengthened my understanding of JOINs, aggregations, subqueries and CTEs for analyzing business data.

I also practiced window functions such as RANK(), DENSE_RANK() and ROW_NUMBER() for customer and product ranking, along with creating a reusable SQL View and Stored Procedure.
